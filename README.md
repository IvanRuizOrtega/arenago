🏟️ Project: Arena.go

The Next-Gen Sports Facility Management System
Arena.go is a premium, high-performance web ecosystem built with Laravel 11, Livewire 3, and Tailwind CSS. It redefines how sports complexes are managed by blending a futuristic Glassmorphism UI with robust business logic, ensuring a seamless experience for owners, staff, and players.

💎 Design Philosophy: "Liquid Crystal"
The entire interface is built using Glassmorphismprinciples:
Translucency: High-contrast frosted glass overlays.
Depth: Multi-layered backgrounds with dynamic ambient glow.
Vibrancy: Neon-inspired accents (Emerald for success, Blue for info, Amber for warnings).
Responsiveness: A mobile-first approach that looks stunning on phones and 4K TV displays.

🚀 Core Features & Business Logic

🏠 Multi-Role Home Experience
For Owners: "Take total control: Your business on a single screen."
For Players: "Your spot guaranteed: If you see it free, it’s yours. No loops."

📅 Advanced Booking & Shift Engine
1-5 Hour Rule: Automated validation to ensure shifts are never shorter than 1 hour or longer than 5 hours.
Anti-Overlap Lock: A real-time database verification system that prevents double-bookings on the same court and time slot.
Livewire Calendar: A drag-and-drop style visual grid for staff scheduling.

📈 Owner Intelligence Dashboard
Live Metrics: Real-time tracking of total revenue, occupancy rates, and new customer growth.
Staff Management: Direct control over facility personnel, shift assignments, and performance.
PQRS & Continuous Improvement: A dedicated module for handling claims, suggestions, and user feedback to iterate the business model.

🍿 On-Site Operations (POS)
Inventory Management: Glass-styled interface for selling hydration, snacks, and renting sports equipment (bibs, balls).
Smart Court Control: Manual and automated lighting triggers and check-in/check-out status monitoring.

📺 Kiosk Mode (TV Display)
A dedicated full-screen view for facility lobbies showing live match countdowns, next-up reservations, and dynamic advertisements.

🛠️ Technical Stack
Backend: PHP 8.4 / Laravel 11.
Styling: Tailwind CSS (Custom Glassmorphism configurations).
Interactions: Alpine.js (Lightweight modals and transitions).
Database: MySQL / PostgreSQL with optimized indexing for time-range queries.

🏁 Getting Started (Init)
Clone: git clone https://github.com
Install: composer install && npm install
Environment: Setup .env with Google Socialite keys and DB credentials.
Migrate: php artisan migrate --seed
Build: npm run dev
Play: Access the dashboard and start the evolution of sports management.
